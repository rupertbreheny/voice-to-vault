# overview
An index of every note voice-to-vault has produced. The view below filters on the `type: transcription` property that each generated note carries, so it finds them wherever they live — no folder structure, tag, or template required.

Views: **all** (newest first), **by topic** (grouped by routing folder), **unsorted** (memos where no trigger word was detected, so these need filing by hand), **flagged dates** (recordings whose date the future-date guard had to correct), **longest**, and **link**.
